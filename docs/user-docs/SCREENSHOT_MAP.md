## Пометки по текущему набору

- `03-welcome-no-organization.png` снят на текущем тестовом пользователе, у которого организация уже настроена. Для точного состояния "без организации" нужен отдельный тестовый пользователь без организации.
- `05-returns-list-empty.png` снят как пустое состояние списка на экране. В текущем тестовом аккаунте есть демо-возвраты, поэтому для полностью нового аккаунта без возвратов нужен отдельный тестовый набор данных.
- `12-refund-section.png` и `17-shipment-section.png` сняты с возврата `10040`, где уже есть возмещение и доставка.
- FAQ не снимаем: этот раздел лучше оставить текстовым и ссылаться из него на профильные разделы.

## Правила для будущих скриншотов

- Использовать демо-данные, не реальные данные клиентов.
- Снимать desktop-версию в ширине `1440px`.
- Оставлять интерфейс на немецком, пока продуктовый UI немецкий.
- Давать файлам стабильные имена с числовым префиксом.
- Переснимать весь набор после заметных изменений layout, форм, статусов, доставки или возмещений.
